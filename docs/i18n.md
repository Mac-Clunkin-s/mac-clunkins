# Internationalisation (i18n)

McCluckin's ships in English, isiZulu (`zu`), Sesotho (`st`) and Setswana (`tn`). The foundation is
in place; the screens are not wired to it yet. This page is how to wire a screen, add strings, and
add translations without stepping on anyone.

## How it works

- `src/i18n/index.ts` is dependency-free. It exports `t(key, params)`, `LOCALES`, `detectLocale`,
  `getLocale`, `setLocale`, `subscribe` and `interpolate`.
- Catalogues are flat JSON maps: `"login.submit": "Log in"`. Placeholders are `{name}`:
  `t('pending.thanksName', { name: 'Thandi' })`.
- **English is the fallback.** A key missing in the active language shows the English text. A key
  missing everywhere shows the key itself, so a gap is visible rather than blank.
- The chosen language is saved in `localStorage` (`mccluckins.locale`); first visit uses the
  browser language if supported, else English. `<html lang>` follows the selection.

## Where strings live

| File | Owner | Purpose |
| --- | --- | --- |
| `src/i18n/locales/en.json` | platform | Existing screens: Welcome, Login, Sign up, Pending, nav, common buttons |
| `src/i18n/locales/{zu,st,tn}.json` | translators | Translations of `en.json` (empty to start) |
| `src/i18n/en.<area>.json` | the feature agent for that area | New strings, e.g. `en.buyer.json`, `en.supplier.json`, `en.driver.json`, `en.admin.json` |
| `src/i18n/<locale>.<area>.json` | translators | Translations of that area, e.g. `zu.buyer.json` |

Every file matching `src/i18n/<locale>.<area>.json` is merged automatically (`import.meta.glob`),
so **feature agents never edit `index.ts` or the base catalogues**. Prefix keys with the area
(`buyer.quote.title`) so two areas can never collide; a test fails if the same key is defined in
two English files.

## Wiring a screen

```tsx
import { useLocale } from '../i18n/useLocale';

export default function Login() {
  const { t } = useLocale();
  return <h1>{t('login.title')}</h1>;
}
```

`useLocale()` re-renders the component when the language changes. Outside React (validation
messages, thrown errors) call `t()` directly, but a component that shows the result must be
rendered via `useLocale()` to update live.

## Integration steps (not done in this PR)

The platform PR deliberately left `App.tsx` and `main.tsx` alone because other branches edit
them. After the feature branches merge, one small follow-up does the wiring:

1. In `src/main.tsx`, wrap `<App />` in `<LocaleProvider>` (from `src/i18n/LocaleProvider`).
2. Replace the language `<select>` in `src/pages/Welcome.tsx` with `<LanguageSwitcher />`
   (`src/components/LanguageSwitcher.tsx`), and mount it in the signed-in header too.
3. Swap hard-coded strings for `t('...')`, screen by screen. The seeded keys in `en.json` already
   match the current copy of Welcome, Login and Pending. The Sign up keys are placeholders: check
   them against `src/pages/SignUp.tsx` when wiring it.

## Adding or translating strings

1. Add the English text to `src/i18n/en.<area>.json` (new feature strings) or `locales/en.json`.
2. Add the translation to `src/i18n/<locale>.<area>.json` or `locales/<locale>.json`, with the same
   key and the same `{placeholders}`.
3. Run `npm run test:i18n` (coverage per language; fails if a language has a key English lacks) and
   `npm test` (also checks placeholders match and every file is a flat map of strings).

```bash
node scripts/i18n-report.mjs                # coverage table
node scripts/i18n-report.mjs --missing=zu   # keys isiZulu still needs
node scripts/i18n-report.mjs --min=60       # CI-style gate: every non-English language >= 60%
```

## Rules of thumb

- Whole sentences as values; never concatenate translated fragments. Use `{placeholders}`.
- Money and dates are formatted with `src/lib/format.ts`, not inside strings. Amounts are cents.
- Don't translate brand names (McCluckin’s) or role identifiers (`buyer`, `supplier`).
- Never put one role's private data (names, prices, contact details) in a string a different role
  can see; translation is not an exemption from the privacy rule.
